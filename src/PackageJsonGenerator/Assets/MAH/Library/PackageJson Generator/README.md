# PackageJson Generator

An Editor window for creating a UPM (Unity Package Manager) `package.json` file from a GUI.

## Requirements

- Unity 6000.0 or later
- `com.unity.nuget.newtonsoft-json` 3.2.1 (installed automatically as a dependency)

## Quick start

1. Select **MAH > Generator > PackageJson Generator Window** from the menu bar.
2. Fill in the required settings (package name, version, display name, description, Unity version, license and author name).
3. Click **Browse** to choose the output folder.
4. Click **Create package.json**.

To edit an existing file, choose its folder and click **Load package.json**.
