# 要求内容：依存パッケージの修正

> 作業ディレクトリ：`.steering/20261020-dependencies-fix/` ／ 作成日：2026-10-20 ／ ステータス：承認済み
> 対象：パッケージ `com.mah.package-json-generator` v1.0.1 ／ 開発環境 Unity 6000.3.26f1（対応 Unity 6000.0 以上）
> 関連する永続的ドキュメント：`Docs/functional-design.md` §3.1・§4.5（依存パッケージの仕様。更新要）、§8（K-1・K-2・K-8・K-11 を修正済みにする。新しく見つけた不具合を K-24 として追加）

## 1. 変更・追加する機能の説明

外部パッケージ（`dependencies`）の入力と出力を、UPM が受け付ける形に直す。UPM の `dependencies` は完全一致のバージョン（例 `"1.2.3"`）しか受け付けないが、今は比較演算子や範囲（`>=1.0.0`、`1.0.0 - 2.0.0`）を出力できてしまい、作った package.json を Package Manager が読み込めない。
あわせて、依存パッケージの名前の重複で生成が例外で止まる問題と、初期値 `com.` のままの行が出力される問題、パッケージ名を手で入力できない問題を直す。
計画書の作業単位 #1。#8（プレビュー版のバージョン）は、この作業で作り直した依存の入力の上に機能を足すので、先にこれを行う。

## 2. ユーザーストーリー

- パッケージの作者として、作った package.json がそのまま Package Manager で読み込めるように、依存パッケージのバージョンは完全一致の形式だけで出力してほしい
- パッケージの作者として、間違えて同じ依存を 2 回登録しても作業が止まらないように、例外ではなくエラーメッセージで知らせてほしい
- パッケージの作者として、プロジェクトに入っていないパッケージも依存に書けるように、パッケージ名を手で入力できてほしい
- 演算子付きの依存を持つ既存の package.json を読み込む利用者として、値がどう変わったか分かるように、変換したことを警告で知らせてほしい

## 3. 受け入れ条件

**出力（Create）**
- [ ] 依存パッケージの入力欄に「条件」（比較演算子の選択）が表示されず、バージョンは Major / Minor / Patch だけを入力する
- [ ] Create した package.json の `dependencies` の値が、すべて `"X.Y.Z"` の形になる（`>`、`<`、`=`、` - ` を含まない）（K-1、K-2）
- [ ] 同じパッケージ名の依存が 2 件以上あるとき、Create を押しても例外が出ず、Console に重複した名前を示すエラーが出て、ファイルは作成・上書きされない（K-8）
- [ ] パッケージ名が初期値 `com.` のまま、または空の行があるとき、その行は出力されず、Console に警告が出る。他の行は出力される（K-11）
- [ ] 依存パッケージが 1 件も無い、または有効な行が 1 件も無いとき、`dependencies` キーは出力されない

**入力**
- [ ] パッケージ名の欄に `com.example.tool` のような 3 要素以上の名前を 1 文字ずつ手で入力でき、確定（Enter かフォーカスアウト）した時点で検証される（K-24）
- [ ] 右側のポップアップでプロジェクトに登録済みのパッケージを選ぶと、名前とバージョンが入る（今の動きを維持する）

**読み込み（Load）**
- [ ] `"1.2.3"` 形式の依存は、そのまま読み込まれる
- [ ] `">=1.2.0"`、`"> 1.2.0"`、`"<1.2.0"`、`"<=1.2.0"` は `1.2.0` として、`"1.0.0 - 2.0.0"` は下限の `1.0.0` として読み込まれ、Console に「どのパッケージの値をどう変えたか」の警告が出る
- [ ] 上のどの形にも当てはまらない値（例 `"1.0.0-preview.1"`、`"file:../foo"`）は、今と同じく読み込まれないが、黙って消えずに Console に警告が出る
- [ ] 読み込みで例外が出ない

## 4. 制約事項

- 編集するのは `src/PackageJsonGenerator/Assets/@MAH/PackageJson Generator/` だけ。作業の最後に配布フォルダへ同期する
- 既存の `.meta` の GUID を変えない。ファイルを削除する場合は `.meta` も一緒に削除する
- エラーと警告の通知は、今の作りに合わせて Console（`Debug.LogError` / `Debug.LogWarning`）に日本語で出す。画面上での通知は #4（K-12）で行う
- Unity 6000.0 に無い API を使わない。パッケージの依存を増やさない
- 識別子の綴り（`PacckageName`、`VersionOperater.cs` など）は直さない（#6 で行う）
- `PackageJsonCreateWindow` の責務の分割はしない（#5 で行う）。今回の修正に必要な範囲だけ変える

## 5. スコープ外（今回やらないこと）

- プレビュー版のバージョン（`1.0.0-preview.1` など）の入力と読み込み：#8 で行う。今回は読み込めないことを警告で知らせるだけ
- バージョン入力で負の値を防ぐこと（K-22）：#5 で行う
- 入力エラーを画面上に表示すること（K-12）：#4 で行う
- `file:` や Git URL などのバージョン以外の依存指定への対応
- Load した依存の名前が正しい形式かの検証（K-18 の一部）：#2 で行う
